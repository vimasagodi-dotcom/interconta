# Analisador SAF-T

Este projeto tem como objetivo analisar e validar ficheiros SAF-T (Standard Audit File for Tax purposes).

## Funcionalidades Planeadas
- Importação e parsing de ficheiros XML SAF-T.
- Validação de estrutura e integridade dos dados.
- Visualização de faturas, clientes, produtos e resumo de impostos.
- Gráficos e relatórios financeiros com base no SAF-T.
